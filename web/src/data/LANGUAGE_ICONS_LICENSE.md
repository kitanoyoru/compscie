# Language icon sources

`language-icons.json` is generated by `scripts/vendor-language-icons.mjs`.

- Brand marks come from [Simple Icons](https://simpleicons.org/) (CC0 1.0). Java uses the
  Simple Icons OpenJDK mark, because Simple Icons has no Java mark.
- The SQL database glyph is drawn for this project.
- Colors are GitHub linguist colors, darkened or lightened per theme to reach 3:1 contrast
  against the app's card surfaces.

Brand marks remain trademarks of their owners. They are used here only to identify the
programming language of a solution.
